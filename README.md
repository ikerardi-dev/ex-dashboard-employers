# ex-dashboard-employers

## Description

In this project, we have created a functional app for both mobile and desktop to monitor and manage employees and their data from HR in a simpler and more intuitive way. We have also added a unique extra feature that allows creating specific events for these employees, like meetings or birthdays, and to keep even better control.
